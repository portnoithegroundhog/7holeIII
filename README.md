# 7holeIII
another revised version of 7hole, finally with custom step patterns in any temperament
I took the original 7hole flute-o-mat and refined it specifically for 3/4" PVC pipe with a Blue Bear tone box. This version, 7hole3, takes into account the internal resistance and end corrections for this specific configuration of flute, just as 7hole2 did. 
The additional feature is the ability to input a custom scale by typing a step pattern. example: 2-2-1-2-2-2-1 for Major scales. The calculator will determine the temperament and recommend hole placement.
